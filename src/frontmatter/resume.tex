\chapter*{Résumé}
\markboth{Résumé}{Résumé}

Ce projet étudie la détection d'intrusions à partir de flux réseau IoT et la
consultation des alertes dans une application de supervision. Il utilise
RT-IoT2022, dont les 123\,117 lignes sont contrôlées puis nettoyées des conflits
d'étiquettes et des doublons. Quatre familles de modèles sont comparées sur des
partitions d'entraînement, de validation et de test, avec trois graines
aléatoires. La sélection retient un gradient boosting par histogrammes pour
distinguer les attaques du trafic normal, puis une forêt aléatoire pour
identifier leur famille.

Une API FastAPI exécute les modèles et enregistre les observations, les
prédictions et les alertes. L'ingestion persistante permet de reprendre les
traitements en échec sans créer de doublons. L'interface React donne accès aux
résultats, aux versions des modèles et à l'historique des qualifications de
l'analyste. Les alertes de signature du laboratoire Suricata y sont identifiées
par leur source.

Sur le test interne associé à la graine~42, la cascade obtient une macro-F1 de
0,9520; la moyenne sur les trois graines est de 0,9686. Les classes rares restent
fragiles : le test ne contient que six flux \texttt{NMAP\_FIN\_SCAN} et sept flux
\texttt{Metasploit\_Brute\_Force\_SSH}. L'étude fournit ainsi une évaluation interne
et un prototype d'investigation. Une collecte NFStream étiquetée et une
évaluation sur un réseau externe restent nécessaires pour en étudier le transfert.
